# kitty

## Purpose

Install and configure the kitty terminal (frosted glass, cursor trail, smooth
scrolling), keep its selection color in sync with the COSMIC accent color, add
a `clear` alias that also wipes scrollback, and make kitty the default terminal
in COSMIC.

## Source of truth

Captured from the reference machine: `~/.config/kitty/kitty.conf`,
`~/.local/bin/kitty-cosmic-colors.sh`, the two user units in
`~/.config/systemd/user/`, the `clear` alias in `~/.bashrc`, COSMIC
`system_actions` and `~/.config/cosmic-mimeapps.list`. Payload lives in
`files/kitty/`. The stray fastfetch shell snippet that was pasted into the live
`kitty.conf` is intentionally not captured. `cosmic-colors.conf` is generated
and is not shipped.

## Files and packages touched

- Package: `kitty` (official).
- `~/.config/kitty/kitty.conf` (0644)
- `~/.local/bin/kitty-cosmic-colors.sh` (0755)
- `~/.config/systemd/user/kitty-cosmic-colors.service` and `.path` (0644)
- `~/.config/kitty/cosmic-colors.conf` (generated by running the script)
- `~/.bashrc`: managed block `kitty-clear` with the `clear` alias. A legacy
  unmanaged copy of the alias (and its old Spanish comment line) is removed.
- `~/.config/cosmic/com.system76.CosmicSettings.Shortcuts/v1/system_actions`:
  created with `Terminal: "kitty"` only when the file does not exist. If it
  exists without that entry the module warns and leaves it alone (merging RON
  is out of scope).
- `~/.config/cosmic-mimeapps.list`: `x-scheme-handler/terminal` and
  `application/x-terminal-emulator` set to `kitty.desktop` under
  `[Default Applications]`; other entries are preserved.
- Unit enabled: `kitty-cosmic-colors.path` (user).

## Hardware detection

none

## Idempotency check

Files are compared byte by byte, the bashrc block and INI lines are checked
before writing, and the path unit is only enabled when not already enabled.
The script is re-run only when it or a unit changed. A second run reports
"Nothing to change".

## Revert

- Restore `kitty.conf`, the script and the units from their
  `*.bak.<timestamp>` files (or delete them if no backup exists).
- `systemctl --user disable --now kitty-cosmic-colors.path`, then
  `systemctl --user daemon-reload`.
- Remove the `# >>> eos-cosmic-setup:kitty-clear >>>` ... `<<<` block from
  `~/.bashrc` (or restore `~/.bashrc.bak.<timestamp>`).
- Remove `~/.config/kitty/cosmic-colors.conf` if wanted.
- Restore `system_actions` and `cosmic-mimeapps.list` from their backups, or
  delete the files if the module created them.
- `sudo pacman -Rns kitty` to remove the package.

## Verification

- `./install.sh --only kitty --dry-run` reports "Nothing to change" after a
  real run.
- `systemctl --user is-enabled kitty-cosmic-colors.path` prints `enabled`.
- `grep -n 'alias clear' ~/.bashrc` shows exactly one line, inside the block.
- `cat ~/.config/kitty/cosmic-colors.conf` shows `selection_background`.
- `shellcheck -x install.sh lib/common.sh modules/*.sh files/kitty/kitty-cosmic-colors.sh`
